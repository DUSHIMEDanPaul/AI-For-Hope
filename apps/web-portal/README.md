# AI for Hope — Next.js Patient & Clinician Portal

This is the central web dashboard application for **AI for Hope**, built with Next.js 14, TypeScript, Tailwind CSS, TanStack Query, and Zustand.

## Core Features
1.  **Patient Hub**: Digital registration, visual triage queue estimations, medical billing invoices, and transaction processing.
2.  **Clinician Dashboard**: Real-time queue view, patient EHR search, diagnostic recommendations, and direct AI DICOM X-ray analysis panel.
3.  **Administrator Analytics**: Clinic performance aggregations, wait-time statistics, disease trends, and resource forecasts.

## Tech Stack Overview
*   **Framework**: Next.js 14 (App Router)
*   **Language**: TypeScript
*   **Styling**: Tailwind CSS
*   **Server State & Caching**: TanStack Query (React Query)
*   **Client State**: Zustand (for lightweight intake multi-step states)

## Getting Started

### Local Installation
```bash
npm install
npm run dev
```

The application runs at `http://localhost:3000`.
